# Learn SecByte Windows Sysinternals, Memory & Permissions CTF Labs

## Introduction

This repository organizes Learn SecByte CTF labs focused on Windows Sysinternals utilities, memory inspection, access permissions, object management, file signatures, process execution, and system administration.

The collection is designed for students, Windows administrators, cybersecurity learners, IT support professionals, and security practitioners developing practical Windows troubleshooting and investigation skills.

## Learning Path

1. **Begin with memory fundamentals:** Explore VMMap and RAMMap.
2. **Learn Windows internals:** Continue with WinObj and the general Windows utilities.
3. **Inspect files:** Practice string inspection and digital signature checks.
4. **Understand permissions:** Work through AccessEnum and AccessChk.
5. **Explore operational tools:** Finish with PsExec, Open Handle Hunt, and PsShutdown.

Follow each lab's prerequisites and adapt the order to your experience.

## How to Use the Labs

1. Open a lab using its direct link.
2. Read the learning objectives and environment requirements.
3. Complete the exercises in the authorized lab environment.
4. Document your commands, observations, and findings.
5. Review unfamiliar Windows concepts and revisit challenging exercises.

Use particular caution with remote execution, permission changes, and shutdown utilities. Test only on systems you own or have explicit authorization to administer.
